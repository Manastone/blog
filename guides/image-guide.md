# 이미지 제작 가이드

> image-maker 에이전트가 읽는 가이드입니다.
> 모든 이미지는 HTML + CSS로 제작하고 Python + Playwright로 PNG 캡처합니다.

---

## 1. 대표 이미지 (썸네일)

### 규격
- **사이즈**: 1080 × 1080px (1:1 정사각형)
- **배경**: 밝은 블루-스카이블루 그라데이션 

### 텍스트 구성
| 요소 | 내용 | 스타일 |
|------|------|--------|
| 메인 텍스트 | 글 제목 | 큰 글씨, 어두운색 |
| 보조 텍스트 | 카테고리 또는 부제 | 작은 글씨, 조금 덜 어두운색  |

- 모든 텍스트는 **가로·세로 중앙 정렬**
- 폰트: `Pretendard` 우선, 없으면 시스템 기본 한글 폰트 (`Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif` 순)
- 우측 하단 또는 좌상단에 **작은 액센트 요소** 배치 (도형, 코드 심볼 `</>`, `{ }`, `#`, `>_` 등 단순한 아이콘)

## 2. 본문 삽입 이미지 — 네 가지 유형

글 내용에 맞게 아래 네 유형 중 하나를 선택한다.

### 유형 1 — 비교 표
**언제**: 제품, 방법, 도구를 나란히 비교할 때

- 열(column)마다 항목 구분이 명확해야 함
- 헤더 행은 강조 배경 처리
- 비교 기준 항목은 왼쪽 열에 고정

### 유형 2 — 단계별 다이어그램
**언제**: 절차나 순서를 시각적으로 보여줄 때

- 단계를 번호 + 간결한 텍스트로 표현
- 단계 간 화살표 또는 연결선 사용
- 너무 많은 단계는 2줄로 나눠 배치

### 유형 3 — 핵심 포인트 카드
**언제**: 3~5개 요점을 한눈에 정리할 때

- 카드 1개당 아이콘(이모지 또는 심볼) + 짧은 텍스트
- 카드 간 균등 간격 유지
- 항목이 3개면 1열, 4~5개면 2열 또는 상단 1 + 하단 2 배치

### 유형 4 — 인용·강조 박스
**언제**: 중요한 한 마디, 핵심 문장을 강조할 때

- 큰따옴표(`"`) 또는 왼쪽 세로선으로 인용 표시
- 핵심 문구만 — 길면 효과가 없음
- 출처나 설명이 필요하면 작은 글씨로 하단에 표기

## 3. 공통 제작 규칙

### 기술 스택
- **제작**: HTML + CSS (인라인 스타일 권장, 외부 파일 의존 최소화)
- **캡처**: Python + Playwright → PNG 저장
- Playwright 기본 예시:
  ```python
  from playwright.sync_api import sync_playwright

  html_content = """..."""  # 이미지 HTML

  with sync_playwright() as p:
      browser = p.chromium.launch()
      page = browser.new_page(viewport={"width": 1080, "height": 1080})
      page.set_content(html_content)
      page.screenshot(path="output.png", full_page=False)
      browser.close()
  ```

### 디자인 원칙
- **배경 톤**: 밝은 분위기 (흰 배경 기본)
- **텍스트 길이**: 최대한 짧게. 이미지는 보조 수단이지 설명문이 아님
- **코드 블록 스타일** 디자인 요소로 적극 활용 가능
  - 모노스페이스 폰트 (`Fira Code`, `Consolas`, `monospace`)
  - 어두운 배경에 밝은 텍스트
  - 괄호, 세미콜론 등 코드 심볼을 장식 요소로 사용

### 파일 저장
- 저장 경로: `output/[주제]/images/[파일명].png`
- 파일명 규칙: 내용을 알 수 있는 짧은 영어 소문자 + 하이픈
  - 예: `thumbnail.png`, `step-diagram.png`, `feature-cards.png`, `quote-box.png`
