## 1. 제목 작성 규칙

### 권장 글자 수
- **20~25자 이내**가 최적 (공백 포함)
- 검색 결과에서 잘리지 않는 범위 기준
- 모바일 기준 약 22자에서 말줄임 처리됨

### 키워드 위치
- **목표 키워드(메인 키워드)는 제목의 앞부분(첫 10자 이내)에 배치**
- 서브 키워드(연관 키워드)는 자연스럽게 뒤에 포함
- 예시: `서울 카페 추천 | 연남동 분위기 좋은 곳 TOP 5`

### 효과적인 제목 패턴
- 숫자 포함: `~하는 7가지 방법`, `TOP 5 추천`
- 연도 포함: `2026년 최신`, `2026 기준`
- 타겟 명시: `직장인을 위한`, `초보자도 따라하는`
- 문제 해결형: `~할 때 꼭 봐야 할`, `~가 안 될 때 해결법`

### 피해야 할 단어·패턴
| 유형 | 예시 | 이유 |
|------|------|------|
| 과도한 특수문자 | `★☆♥ 최고 맛집!!` | 스팸성으로 인식 |
| 의미 없는 반복 | `맛집 맛집 맛집 추천` | 키워드 스터핑으로 감점 |
| 낚시성 문구 | `충격!! 절대 몰랐던~` | 클릭 미끼성 판정 |
| 너무 긴 제목 | 35자 초과 | 검색 결과에서 노출 불리 |
| 광고성 직접 표현 | `협찬 필수 구매`, `무조건 1등` | 어뷰징·광고 판정 위험 |

## 2. 본문 구조

### 권장 글자 수
- **최소 1,500자 ~ 권장 2,000~3,000자** (공백 제외 기준)
- 경쟁이 높은 키워드일수록 상위 노출 글의 글자 수를 벤치마킹
- 여행·맛집 리뷰 등 사진 중심 포스팅은 예외적으로 짧아도 허용되나, 텍스트 품질이 더 중요

### 도입-본론-결론 비율
```
[도입부]  약 10~15%
- 검색 의도(사용자가 왜 이 글을 찾는지)에 바로 응답
- 핵심 정보 예고 또는 공감 유발 문장으로 시작
- 첫 2~3문장 안에 메인 키워드 자연스럽게 삽입

[본론]    약 70~80%
- 소제목(H2/H3 수준)으로 단락 구분
- 실제 경험, 구체적 수치, 비교 정보 포함
- 단락당 3~5문장 권장 (가독성 유지)
- 목록(리스트), 표, 이미지를 혼합 배치

[결론]    약 10~15%
- 핵심 요약 또는 실행 가이드 제시
- 독자에게 다음 행동 유도 (관련 글 링크, 댓글 유도 등)
```

### 소제목 활용 원칙
- 소제목은 **3~6개** 수준으로 구성 (글 길이에 비례)
- 소제목에도 서브 키워드 포함 권장
- 소제목 간격: 약 300~500자마다 1개 소제목
- 네이버 에디터의 **'제목1', '제목2' 스타일** 적극 활용 (구조화 신호로 인식됨)

### 가독성 향상 팁
- 한 문단은 5줄 이내로 제한
- 중요 정보는 **굵게** 또는 인용구 블록 처리
- 표, 번호 리스트, 불릿 리스트 적극 활용
- 줄바꿈을 자주 사용해 모바일 가독성 확보

## 3. 키워드 밀도와 배치

### 키워드 밀도 가이드
- **메인 키워드**: 전체 글에서 3~5회 자연스럽게 등장
- **서브 키워드(LSI 키워드)**: 1~3회, 유사어·연관어 형태로 활용
- 1,500~2,000자 기준 총 키워드 등장 횟수: **5~6회** 적정
- 과도한 반복(동일 키워드 7회 이상)은 어뷰징으로 감점 가능

### 키워드 배치 우선순위
| 위치 | 중요도 | 권장 사항 |
|------|--------|----------|
| 제목 | ★★★★★ | 첫 10자 이내 배치 |
| 도입부 첫 2~3문장 | ★★★★☆ | 자연스럽게 1회 |
| 소제목 | ★★★★☆ | 1~2개 소제목에 포함 |
| 본문 중반부 | ★★★☆☆ | 문맥에 맞게 반복 |
| 마지막 단락 | ★★★☆☆ | 마무리 문장에 1회 |
| 이미지 파일명/설명 | ★★☆☆☆ | 키워드 포함 권장 |

### 키워드 전략 팁
- **황금 키워드**: 월간 모바일 조회수 1,000~10,000 사이의 틈새 키워드 공략
- 신규 블로그는 초기 2개월간 월간 조회수 1,000 이하 키워드부터 시작
- 연관 검색어(자동완성어)에 나오는 세부 키워드 적극 활용
- 키워드를 단순 반복하지 말고 유의어·확장어로 변형 사용

## 4. 이미지 최적화

### 적정 이미지 수량
- **기본 권장: 5~13장** (상위 노출 1~5위 평균값 참고)
- 여행·맛집·뷰티 리뷰: 20~40장도 유효
- 정보성 글(how-to, 가이드): 5~10장으로 충분
- 텍스트 없이 이미지만 많은 구성은 오히려 감점 요인

### 대표 이미지(썸네일) 규격
- **권장 사이즈: 1:1 비율 (정방형) 또는 16:9 (가로형)**
- 최소 해상도: **300×300px 이상**
- 권장 해상도: **750×750px ~ 1200×900px**
- 파일 형식: JPG, PNG (WebP도 허용)
- 파일 용량: **2MB 이하** 권장 (로딩 속도 영향)
- 썸네일 지정을 별도로 하지 않으면 본문 첫 번째 이미지가 자동 적용됨

### 이미지 최적화 규칙
- **직접 촬영한 오리지널 사진** 사용 권장 (D.I.A. 알고리즘이 독창성 반영)
- 타 사이트에서 무단 스크랩한 이미지는 감점 요인
- 동일 이미지를 여러 포스팅에 재사용할 경우, 크롭·리사이징·텍스트 추가 등 편집 후 사용
- 이미지 파일명에 키워드 포함 권장: `서울-카페-추천.jpg` 형식
- 이미지 간격 배치: 300~500자 텍스트마다 1장씩 배치하면 체류시간 향상

### Alt 텍스트(대체 텍스트)
> 네이버 블로그 에디터에서는 이미지 업로드 후 '이미지 설명' 입력란 활용

- 이미지의 내용을 **20자 이내**로 간결하게 설명
- 메인 키워드 또는 서브 키워드 자연스럽게 포함
- 예시: `서울 연남동 감성 카페 인테리어` / `강남구 맛집 파스타 메뉴`
- "이미지1", "사진" 같은 무의미한 텍스트는 SEO 효과 없음
- 접근성(시각 장애 사용자)과 검색 크롤러 모두를 위한 설명문 작성

## 5. 해시태그 활용법

### 기본 원칙
- **5~10개**가 최적 (최대 30개까지 가능하나 과도한 태그는 역효과)
- 네이버는 해시태그를 **주제 분류 및 카테고리 판단 신호**로 활용
- 검색 노출보다는 **스마트블록·주제 탭 분류**에 영향을 미침

### 해시태그 구성 전략
```
[구성 권장 비율]
- 메인 키워드 태그 (1~2개): #서울카페추천, #연남동카페
- 세부 주제 태그 (2~3개):   #분위기좋은카페, #혼자가기좋은카페
- 카테고리 태그 (1~2개):    #카페투어, #카페일상
- 트렌드/계절 태그 (1~2개): #2026카페추천, #봄카페
```

### 태그 작성 팁
- 공백 없이 붙여서 작성: `#서울카페` (O) / `#서울 카페` (X)
- 너무 광범위한 태그(`#일상`, `#맛스타그램`)는 경쟁이 높아 효과 낮음
- 블로그 주제(카테고리)와 일치하는 태그 우선 사용
- 글 내용과 무관한 인기 태그 남용은 어뷰징 신호로 작용

### 2026년 해시태그 변화
- 네이버 **통합탭(피드형 검색)** 전환 이후, 해시태그는 알고리즘이 주제 의도를 파악하는 보조 데이터로 중요도 증가
- 단순 검색 유입보다 **스마트블록 선택 기준**에 더 큰 영향

## 6. 네이버 알고리즘 이해 (C-Rank & D.I.A.+)

### C-Rank (채널 신뢰도 알고리즘)
> 블로그 전체의 신뢰도와 전문성을 평가하는 채널 단위 알고리즘

**평가 요소 및 가중치 (추정)**
| 요소 | 비중 | 설명 |
|------|------|------|
| 주제 전문성 | 약 40% | 특정 카테고리 집중 포스팅 비율 |
| 활동 지속성 | 약 30% | 꾸준한 발행 주기 유지 여부 |
| 사용자 반응 | 약 20% | 댓글, 공감, 공유, 체류시간 |
| 콘텐츠 품질 | 약 10% | 글자 수, 이미지, 구조화 정도 |

**C-Rank 향상 전략**
- 하나의 주제에 집중 (잡블로그보다 전문 주제 블로그가 5배 유리)
- 동일 카테고리 포스팅 **최소 50개 이상** 누적 시 전문성 인정
- 주 2~3회 이상 꾸준한 발행 (일정한 리듬 중요)
- 방문자와의 댓글 소통 적극 유지
- 공유(Share)가 좋아요·댓글보다 알고리즘 점수에 더 유리

---

### D.I.A.+ (Dynamic Information Analysis, 문서 품질 알고리즘)
> 개별 포스팅의 정보 품질과 사용자 검색 의도 충족도를 평가하는 알고리즘

**핵심 평가 기준**
1. **검색 의도 충족도**: 사용자가 "왜" 이 키워드를 검색했는지 파악 후 직접적인 답 제공
2. **독창성**: 직접 촬영한 사진, 개인 경험, 고유 관점 포함 여부
3. **정보 정확성**: 팩트 기반 구체적 수치·데이터 포함
4. **가독성**: 구조화된 흐름, 단락 구분, 소제목 활용
5. **체류시간**: 사용자가 글을 끝까지 읽는지 여부 (이탈률 반영)

**2025~2026년 업데이트 포인트**
- AI/GPT 기반 콘텐츠 품질 분석 도입: 단순 키워드 나열이 아닌 **글의 의도·독창성·전문성** 판단
- **실사용자 행동 데이터** 반영 비중 증가: 재방문율, 댓글, 공유 등
- **Topic Authority(주제 권위)** 개념 강화: 잡블로그보다 전문 블로그 우대
- **통합탭(스마트블록)** 체제 하에서 AI가 사용자 의도에 맞는 글을 직접 선별

**D.I.A.+ 알고리즘이 좋아하는 콘텐츠 패턴**
- ✅ 질문형 소제목 + 바로 아래 명쾌한 답 제공 (AEO 구조)
- ✅ 개인 경험 + 구체적 수치/비교 포함
- ✅ 직접 촬영 사진 + 오리지널 콘텐츠
- ✅ 결론을 먼저 제시하고 근거를 설명하는 역피라미드 구조
- ✅ 체류시간을 높이는 표, 리스트, 비교 정보 배치
- ✅ 연관 글 링크로 내부 링크 구성 (블로그 내 다른 글 연결)

## 7. 어뷰징 판정 기준 및 금지 사항

> ⚠️ 네이버는 공식적으로 "저품질 블로그"라는 개념을 인정하지 않지만,  
> 아래 행위들은 검색 결과 하락(3페이지 강등) 또는 노출 제외로 이어질 수 있음

### 콘텐츠 관련 어뷰징

| 행위 | 설명 |
|------|------|
| 키워드 스터핑 | 동일 키워드를 비자연스럽게 7회 이상 반복 삽입 |
| 복사·붙여넣기 | 타 사이트 콘텐츠 무단 전재 (표절 감지 알고리즘 작동) |
| AI 단순 생성글 무수정 발행 | AI 생성 텍스트를 개인 경험·팩트체크 없이 그대로 발행 |
| 내용 없는 글자수 채우기 | 의미 없는 문장 반복으로 글자수만 늘리는 행위 |
| 글 내용과 무관한 제목 | 낚시성 제목으로 클릭 유도 후 무관한 내용 제공 |

### 운영 방식 관련 어뷰징

| 행위 | 설명 |
|------|------|
| 과도한 광고·협찬 포스팅 | 글 전체가 상업적 홍보 목적, 대가성 미표기 시 제재 |
| 매크로·자동화 포스팅 | 자동화 도구를 이용한 대량 발행 |
| 이슈 키워드 남용 | 실시간 검색어·트렌드 키워드에 무관한 내용 끼워넣기 |
| 스팸성 댓글 교환 | 댓글 품앗이, 의미 없는 "잘 보고 갑니다" 매크로 댓글 |
| 동일 이미지 재사용 | 편집 없이 여러 포스팅에 동일 이미지 반복 사용 |

### 구조·기술 관련 어뷰징

| 행위 | 설명 |
|------|------|
| 지나치게 많은 해시태그 | 내용과 무관한 인기 태그 30개 도배 |
